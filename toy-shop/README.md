# В’язані іграшки

Навчальний інтернет-магазин на React, Vite, React Router та JSON Server. Дані
товарів, користувачів і замовлень зберігаються у `db.json`.

## Запуск

У папці `toy-shop` встановіть залежності та запустіть JSON Server і Vite у
двох терміналах:

```sh
npm install
npm run server
npm run dev
```

Vite проксує `/api` до JSON Server на порту `3000`.

## Сторінки та API

- Сторінки: `/`, `/catalog`, `/product/:id`, `/cart`, `/login`, `/register`,
  `/checkout`, `/account`.
- Товари: `GET /api/products`, `GET /api/products/:id`.
- Користувачі: `GET /api/users?email=:email`, `POST /api/users`,
  `PATCH /api/users/:id`.
  Для перенесення старих записів із відкритим паролем використовується
  `PUT /api/users/:id`.
- Замовлення: `GET /api/orders?userId=:id`, `POST /api/orders`.

Нові паролі зберігаються у вигляді PBKDF2-хешу із випадковою сіллю, а не
відкритим текстом. Під час першого успішного входу старий запис оновлюється.
Це лише навчальна реалізація: JSON Server не забезпечує справжню серверну
автентифікацію, тому не використовуйте справжні облікові дані.

У налаштуваннях кабінету можна змінити пароль після перевірки поточного
пароля. Вихід очищує локальну сесію у поточному браузері; JSON Server не
керує сеансами на інших пристроях.

Замовлення можна оформити лише після входу. Кожне замовлення містить `userId`,
перелік товарів із цінами на момент оформлення, суму, дату та статус. У
кабінеті показуються лише замовлення поточного користувача.
